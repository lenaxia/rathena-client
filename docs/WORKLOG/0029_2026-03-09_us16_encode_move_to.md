## Design Decisions

- `[5]byte` return (not `[]byte`) — enables 0 allocs/op on the encode path; callers use `p[:]` slice when writing to net.Conn
- `packing.EncodePosDir(req.X, req.Y, 0)` — direction always 0 for walk requests (walk packet carries no direction)
- `_ = packetver` — 0x035F is the only packet ID for move_to; no PACKETVER branching needed
- Deliberate deviation from SemanticDB canonical param `Coords [3]byte` — X/Y unpacked for caller ergonomics; documented in file header
