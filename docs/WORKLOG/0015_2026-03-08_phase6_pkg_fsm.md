## Design Decisions

### `pkg/fsm` design invariants preserved
- Zero goroutines in the library: `Connect()` is fully synchronous; all goroutines
  are in the test's scripted server stubs, not in the FSM
- Zero `net.Dial` calls: FSM takes a `Dialer` from the caller
- After `OnReady` fires, FSM holds no conn reference
- `StepTimeout` applied via `conn.SetDeadline` before each read

### 0x0081 disambiguation (char server)
`0x0081` is shared by `SC_NOTIFY_BAN` (3 bytes) and `HC_NOTIFY_ZONESVR` (28 bytes, pre-20170315).
The char session lengths table defaults to `t[0x0081]=3` (SC_NOTIFY_BAN). The FSM overrides
this to 28 via `charSess.SetLength(0x0081, 28)` for `pv < 20170315`, so the framing engine
consumes a full HC_NOTIFY_ZONESVR frame. The handler then disambiguates by checking `len(data)`.

### Missing map auth-phase packets in lengths_map.go
`lengths_map.go` (US-02, still open) is missing `0x0073`, `0x0074`, `0x02EB`, `0x0A18`.
The FSM pre-registers them via `mapSess.SetLength` in `runMapPhase`. Added `SetLength`
to `MapSession` for this purpose (consistent with `LoginSession` and `CharSession`).

### Char list paging (pv >= 20130000)
- Server sends `0x082D` (slot info) → FSM ignores, stays
- Server sends `0x006B` (partial chars) → accumulate raw bytes
- Server sends `0x09A0` with `total` → FSM sends `0x09A1` × total
- Server sends `0x099D` pages → accumulate until `pagesRecv >= pagesTotal`
- Then call `OnCharList(rawChars)` → get slot → send `0x0066`

### Obfuscation on map auth packets
`encodePacketID(mapSess, pkt)` reads the packet ID from `pkt[0:2]`, calls `mapSess.Encode`,
and writes the obfuscated ID back to `pkt[0:2]` before writing to socket. This applies to
`0x0436`, `0x007D`, and `0x007E/0x0360` in sequence.
